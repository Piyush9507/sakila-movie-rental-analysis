# sakila-movie-rental-analysis
End-to-end Movie Rental Business Analysis using the Sakila Database. Built SQL queries for data extraction and analysis, developed interactive Power BI dashboards, and generated business insights on revenue trends, customer behavior, store performance, and film category analytics.

# 🎬 Sakila Movie Rental Analysis

SQL + Power BI project analyzing the Sakila Movie Rental Database to uncover insights into revenue trends, customer behavior, store performance, and film category analytics.

## Tools Used
- SQL (MySQL)
- Power BI
- DAX
- Excel / Power Query

## Dashboard Highlights
- Revenue & Rental Performance
- Customer Analysis
- Store Performance Comparison
- Film & Category Analysis
- Interactive Visualizations

## Key Insights
- Identified top-performing film categories and customers.
- Analyzed revenue trends and store contributions.
- Evaluated inventory distribution across film ratings.
- Generated actionable business recommendations.
